# Definition of Done

A task is not complete until applicable checks pass.

Before completing a task:

- TypeScript compiles.
- Relevant lint passes.
- Relevant tests pass.
- Relevant build passes.
- No debug code remains.
- No commented-out implementation remains.
- No unrelated files were changed.
- Public API changes are intentional.
- Configuration changes are documented when necessary.
- README is updated when developer setup changes.

Final response must include:

- What changed.
- Important technical decisions.
- Files materially changed.
- Commands executed.
- Test/build/lint results.
- Any known limitations or follow-up work.
