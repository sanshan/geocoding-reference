# React

- Prefer functional components.
- Keep components focused.
- Separate data fetching from presentation where useful.
- Avoid unnecessary state.
- Do not duplicate state that can be derived.
- Avoid unnecessary effects.
- Keep API communication centralized.
- Handle loading, empty, success, and error states.
- Keep map state and search state synchronized explicitly.
- Do not place application business logic directly in JSX.
- Maintain accessibility for interactive controls.
