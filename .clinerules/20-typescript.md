# TypeScript

- Keep TypeScript strict.
- Prefer precise types.
- Avoid `any`.
- Prefer `unknown` over `any` for untrusted values.
- Narrow unknown values explicitly.
- Prefer discriminated unions where appropriate.
- Avoid unnecessary type assertions.
- Do not use `as` merely to silence compiler errors.
- Prefer explicit domain types for important concepts.
- Keep functions small and focused.
- Prefer immutable values where practical.
- Do not introduce enums unless they provide a concrete benefit.
- Avoid hidden side effects.
- Handle nullable and optional values explicitly.
