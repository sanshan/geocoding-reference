# Nx

This repository is an Nx workspace.

Before adding or changing Nx configuration:

- Inspect `nx.json`.
- Inspect the target project's configuration.
- Inspect existing workspace conventions.
- Prefer Nx generators where appropriate.
- Do not manually reproduce configuration that Nx already manages.

Use Nx targets for:

- build
- lint
- test
- typecheck
- serve

Prefer commands such as:

pnpm nx build <project>
pnpm nx lint <project>
pnpm nx test <project>
pnpm nx typecheck <project>

When a task affects only one project, do not run every target in the workspace unless necessary.

Respect project boundaries and dependency direction.
